# DRAM 世代覆盖方法

本页只规定跨厂商调研方法。每个厂商的实际范围、编码段、来源和历史补全记录维护在 [PN 索引](README.md) 指向的 DRAM 文章中。

## 调研矩阵

按厂商逐类核对公开资料，不以少量热门 PN 代表整条产品线：

| 类别 | 调研方向 |
| --- | --- |
| 标准 DRAM | SDR、LPSDR、DDR 各世代 |
| 低功耗 DRAM | LPDDR 各世代及 X 变体 |
| 图形 DRAM | GDDR 各世代及 X 变体 |
| 特殊 DRAM | RLDRAM、HBM、HMC；先核对任务授权范围 |

同一系列可能跨标准世代；按产品线/世代拆编码段表，优先补充速率、速度档位和拓扑。已确认容量/位宽编码段可以支持新的容量组合，物理堆叠仍需要独立依据。
