# PN ↔ Flash ID 匹配：FDB 87 实施与审计

日期：2026-09-15。本文记录本地来源、规则行为及审计结果，不作为新增 PN 编码段或芯片物理参数的外部证据。

匹配规则见 [FDBGen](../../FDBGEN.md#pn-与-flash-id-关联)，本文只保留本次审计的样本与测量值。

## 全量数据口径

来源：同目录约定的 `../fdfdb` 原始支持列表与 extra；未修改来源文件。生成版本从 86 更新至 87。

新规则在源候选中共裁剪 1,414 个唯一 PN↔ID 对，包含上一版本规则已经会裁剪的候选。不得把它们全部计为“新增纠错”。按旧、新精确键差异统计为移除 581 条、增加 309 条；其中包含完整 PN 恢复及来源关系重新保留，不能直接当作准确率指标。

## 本次未解决的观测

- SpecTek 73 个 PN 中，36 个可独立完成裸 NAND 解码；其余包括缺封装、未确认配置、非标准短名，仍保留来源记录。
- 源 `iddb.s/p/b` 有 154 个 ID/字段级多值冲突，本次未将它们认定为原生几何。
- 来源 PN 的物理参数未在本轮改写；未知编码和截断输入的处理边界见 [关联规则](../../FDBGEN.md#未知与资源消费) 与 [审计](../../FDBGEN.md#参数)。
